# Movie Ticket Booking Management Application

## Overview

A Pega Platform application developed for CineWave Entertainment to manage movie ticket booking requests from customer submission through show availability, approval, booking execution, and confirmation.

## Technology

- Pega Platform / Pega Infinity
- Pega Blueprint
- Case Management
- Data Modeling
- Workflow Automation

## Case Type

Movie Ticket Request

## Workflow

1. Initial Stage
2. Availability
3. Approval
4. Booking Execution

## Data Objects

- Customer
- Movie
- Show
- Auditorium

## Features

- Customer booking request
- Movie and show selection
- Show availability
- Seat availability
- Customer confirmation
- Booking processing
- Booking confirmation
- Payment and booking details
